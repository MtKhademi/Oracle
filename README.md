# دارایی · Darayi

اپ موبایل فارسی برای دیدن سرمایه‌ها در یک نگاه. ساخته‌شده با Expo، React Native و TypeScript؛ بدون سرور، ورود کاربر، API قیمت یا همگام‌سازی ابری.

## نسخهٔ اول

- رابط تیره، سرمه‌ای و طلایی؛ چیدمان راست‌به‌چپ و فونت Vazirmatn بسته‌بندی‌شده در اپ.
- طلای فیزیکی برحسب گرم، صندوق‌های طلا مانند عیار و گنج برحسب واحد، پول نقد و رمزارزها (تتر، بیت‌کوین، اتریوم و نام‌های دلخواه).
- ثبت، ویرایش و حذف با تأیید؛ نمایش جمع ارزش، بهای خرید موجود، سود/زیان و ترکیب سرمایه.
- ورود `.xlsx`، `.xls` و `.csv`، پیش‌نمایش قبل از ثبت و خروجی اکسل برای پشتیبان‌گیری.
- ذخیره روی دستگاه با AsyncStorage. دادهٔ نمونه فقط با انتخاب کاربر نمایش داده می‌شود و هرگز خودکار وارد سبد واقعی نمی‌شود.

## اجرا

Node.js 22.13 یا جدیدتر و npm نصب باشد:

```sh
npm ci
npm start
```

با Expo Go سازگار با SDK 57، QR را اسکن کنید. گوشی و رایانه باید به یک شبکه دسترسی داشته باشند. اگر Expo Go موجود شما این SDK را پشتیبانی نمی‌کند، از development build یا ساخت APK استفاده کنید. برای پیش‌نمایش مرورگری:

```sh
npm run web
```

سرور توسعه فقط برای توسعه است؛ اپ نصب‌شده برای مدیریت داده‌ها به سرور نیاز ندارد.

## APK اندروید

فایل `eas.json` برای APK داخلی آماده است. ساخت APK در این تحویل انجام نشده و به محیط Android یا حساب Expo نیاز دارد.

```sh
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

## قرارداد اکسل

از بخش «فایل‌ها»، الگوی خالی را بگیرید. فقط اولین شیت خوانده می‌شود. نام و ترتیب ستون‌ها دقیقاً این‌هاست:

| شناسه | نوع | نام | مقدار | قیمت واحد (تومان) | بهای خرید کل (تومان) |
|---|---|---|---:|---:|---:|
| gold-18 | طلای فیزیکی | طلای ۱۸ عیار | 12.5 | 7500000 | 85000000 |
| ayar | صندوق طلا | عیار | 1200 | 28500 | 30000000 |
| cash-bank | پول نقد | حساب بانکی | 42000000 | 1 | |
| btc | ارز دیجیتال | بیت کوین | 0.003 | 10000000000 | |

**این اعداد فقط مثال‌اند؛ قیمت روز یا دارایی واقعی کاربر نیستند.**

- قیمت‌ها همه به **تومان** هستند. برای طلای فیزیکی، قیمت هر گرم مطابق عیار همان طلاست. برای رمزارز، قیمت یک واحد کامل به تومان است.
- برای پول نقد، مقدار برابر موجودی تومانی و قیمت واحد دقیقاً `1` است.
- بهای خرید، **کل هزینهٔ خرید همان ردیف** است؛ اختیاری است. خالی یعنی نامعلوم و صفر یعنی واقعاً صفر. سود فقط برای ردیف‌های دارای بهای خرید محاسبه می‌شود.
- شناسه پایدار است: ورود مجدد با همان شناسه ردیف را جایگزین می‌کند؛ تعداد و مبلغ جمع نمی‌شوند. برای دو حساب جدا شناسه‌های جدا بنویسید.
- مقدار باید مثبت باشد، قیمت غیرمنفی و تعداد واحد صندوق صحیح باشد. ردیف خطادار کل ورود را متوقف می‌کند؛ هیچ ورود ناقصی ذخیره نمی‌شود.
- فایل حداکثر ۵ مگابایت و ۲۰۰۰ ردیف دارایی باشد. فرمول‌ها پشتیبانی نمی‌شوند؛ Paste Values کنید. اعداد فارسی، عربی و لاتین قابل قبول‌اند.
- خروجی را در جای امن نگه دارید. ورود فایل پشتیبان شناسه‌های آن را upsert می‌کند و ردیف‌های دیگر را حذف نمی‌کند.

## نگهداری داده‌ها

AsyncStorage یک گاوصندوق رمزگذاری‌شده نیست. در نسخهٔ مرورگری داده‌ها متعلق به همان مرورگر و آدرس هستند. با حذف برنامه یا پاک‌کردن داده‌های مرورگر ممکن است از بین بروند؛ از بخش فایل‌ها پشتیبان بگیرید. هیچ داده‌ای به GitHub یا سرویس دیگری ارسال نمی‌شود. فایل‌های دادهٔ شخصی در `.gitignore` هستند.

## بررسی‌ها

```sh
npm run typecheck
npm test
npm run build:web
```

تست‌ها شامل خواندن اعداد فارسی، اعتبارسنجی، ورود دوباره، حفظ ردیف‌های دیگر، بهای خرید ناقص و رفت‌وبرگشت فایل واقعی XLSX هستند. ساخت وب جای تست روی گوشی اندروید/iOS را نمی‌گیرد.

## ساخت مخزن خصوصی

اگر مخزن هنوز ایجاد نشده، در پوشهٔ پروژه پس از ورود به GitHub CLI:

```sh
git init -b main
git add .
git commit -m "Initial offline asset manager"
gh auth login
gh repo create MtKhademi/Darayi --private --source=. --remote=origin --push
```

طلب‌ها، بدهی‌ها و وام‌ها خارج از محدودهٔ نسخهٔ اول‌اند. ابتدا تجربهٔ ثبت سرمایه‌ها تثبیت می‌شود.
